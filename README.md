# campusflow_platform_choice

Atelier de la séance 1 du cours de programmation mobile : choisir la plateforme de CampusFlow.

## Contenu

- 01_fiche_comparative.md : les 14 critères Android / iOS appliqués à une application étudiante en Afrique francophone.
- 02_autopsie_windows_phone.md : trois causes de l'échec de Windows Phone, classées par poids, avec une source pour chacune.
- 03_decision_campusflow.md : la décision (cible, plateformes, approche) en un paragraphe justifié.
